# Разработка и локальный Git

## Окружение

Проверенная версия: Flutter 3.50.0 stable (`ab2912035e160d9cad6306df307576da6128ebdb`), Dart 3.14.0. Нужны JDK 21 (`JAVA_HOME`) и Android SDK (`ANDROID_HOME`), Android min API 24. Gradle/AGP/Kotlin закреплены в `android/`; зависимости Dart — в `pubspec.lock`. Не обновлять их попутно.

`FLUTTER_SDK` может указывать SDK вне PATH. Команды запускаются из корня проекта. `android/local.properties` — локальный сгенерированный файл, не переносить пути чужого компьютера. Gradle wrapper включён в Git, чтобы нативные проверки не зависели от случайных сгенерированных файлов.

## Обычное изменение

```sh
make check
# При затрагивании нативного плеера:
make native-test
```

Менять существующий модуль по карте архитектуры. Форматировать `lib/` и `test/`, использовать имеющиеся fake API/video/native. По окончании проверить `git diff --check`, staged-файлы и обновить затронутую документацию. Сначала рабочий код/проверка, затем коммит. Не создавать копии инструкций для каждого AI-редактора: общий источник — `AGENTS.md`.

## Подпись и выпуск

Единый источник правил выпуска и восстановления ключа — [RELEASING.md](RELEASING.md). Не копировать CI/signing-конфигурацию MJReader: совпадает структура работы, а не идентификаторы приложений.

## Git и локальные данные

Это локальный репозиторий; remote не задан. Исходники, lockfile, лицензии, тесты и Gradle wrapper отслеживаются. `.signing/`, APK, `dist/`, Pub/Gradle/Flutter cache, build, `.env*`, локальные properties и тестовые выходы игнорируются. Не использовать `git add -f` для обхода этих правил.

`tools/repo_check.py` проверяет наличие обязательных исходников/Gradle wrapper, состав индекса, размеры и внутренние ссылки в актуальной документации. Это защита от случайного включения приватных путей, а не универсальный сканер содержимого секретов: состав diff/index всё равно читать перед коммитом. Не публиковать публично исходные медиа/исследованные материалы без отдельного решения пользователя.

Локально включить защитный pre-commit: `make hooks`. Он проверяет целостность исходников, индекс/ссылки и whitespace без сборки/устройств. В текущем рабочем репозитории включён; Git не переносит локальную настройку hooksPath при clone, поэтому в новом checkout включается явно.
