# Выпуск и восстановление

## Совместимость

- Имя приложения: MJAnime; applicationId `dev.independent.animetka_tv`.
- Единственный источник версии/versionCode: `pubspec.yaml`.
- Приватный ключ: `.signing/release.jks`; properties: `.signing/key.properties`. Оба вне Git. Не выводить секреты в чат/логи.
- Публичный ожидаемый сертификат: [release-certificate.sha256](release-certificate.sha256). Сверять перед выдачей; не менять ради прохождения проверки.
- Установленная копия обновляется только APK с **тем же сертификатом**. Не советовать удаление приложения: это удаляет его приватные настройки и историю.

## Локальный выпуск

1. Явно повысить versionName и versionCode в `pubspec.yaml`, обновить CHANGELOG.
2. `make check`; при нативных изменениях `make native-test`.
3. `make build` использует существующий ключ, прогоняет проверки и собирает обе ARM ABI.
4. Для видео/GPU проверить точный полученный APK во всех режимах на отдельно разрешённом изолированном эмуляторе, согласно [TESTING](TESTING.md). Успешный fallback не считать работой CNN.
5. Сверить package, versionName/versionCode, сертификат и SHA-256. Наличие APK и код возврата build не заменяют эти проверки.
6. Выдать проверенный файл из `dist/`. Не пересобирать между тестом и выдачей. Сохранить ограничения проверки; эмулятор не доказывает FPS проектора.

GitHub Actions, публичный remote, теги и Releases для этого локального репозитория не настроены. Создавать их только по запросу. Не заимствовать CI/secrets/версию/подпись MJReader: у MJAnime отдельная identity.

## Чистый checkout и потеря ключа

На новом checkout `setup_signing.py` при отсутствии обоих файлов создаёт **новую** локальную identity — только для отдельной установки/разработки. Для обновления прежнего MJAnime сначала приватно восстановить исходный ключ и properties. Если отсутствует только один файл пары, скрипт отказывается работать: восстановить согласованную резервную копию, не удалять оставшийся файл ради обхода проверки.

Путь ключа разрешается относительно проекта: `.signing/release.jks`. Старое поле `storeFile` в properties больше не используется, поэтому перенос папки не меняет подпись и не требует редактирования секретов. Проверить совпадение сертификата с доверенным предыдущим APK через Android Build Tools `apksigner verify --print-certs`. Публичный fingerprint не является приватным ключом.

Если проверка/сборка провалилась — исправить исходники и повторить затронутые проверки. Не подменять ожидаемый fingerprint, не отключать тесты и не перезаписывать ранее выданный файл под видом прежней версии.
