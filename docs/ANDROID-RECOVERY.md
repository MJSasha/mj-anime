# Восстановление Android-платформы — 14.11.2026

При переносе проекта в `MJAnime` обнаружено отсутствие корневой `android/`. В восстановленной пользователем старой папке остались только сгенерированные файлы. Flutter-код, локальный video_player fork, тесты, ресурсы приложения, исходный release APK и приватная подпись сохранились.

## Источники восстановления

- Сохранённый `dist/MJAnime-1.7.0.apk`, SHA-256 `c9f4d4804761fa9219f201d938e7532466a3ed303d82b4497cd74c8502d02527` (сам APK вне Git).
- Сохранённые JVM-классы `MainActivity.class` и `InstallResultReceiver.class` из предыдущей release-сборки. Их декларации, channel-dispatch, проверки update package/version/cert и Back прочитаны через существующий JADX headless 0.7.1. APK и классы не исполнялись.
- Манифест, vector/adaptive/monochrome icons, splash, цвета и TV banner декодированы из того же APK; в исходники перенесены только app-owned ресурсы, без копирования ресурсов зависимостей.
- Каркас Gradle/wrapper создан Flutter 3.50.0 stable той же ревизии. Восстановлены прежние AGP/Kotlin/Gradle, package, API 24 minimum и ARMv7/ARM64.

Это восстановленный Kotlin-код по сохранённому бинарному поведению, а не побайтное возвращение утраченных текстовых файлов/комментариев. Нативные обработчики: диагностический режим локального видео, версия, громкость, keep-screen-on, речь, URL, системный Back, выбор/проверка/установка обновления и callback receiver. Сессия неудавшейся установки явно отслеживается и abandon-ится при ошибке.

Путь к **тому же** приватному keystore сделан относительным: `.signing/release.jks`. Ключ и пароли не создавались и не заменялись. Публичный ожидаемый fingerprint — [release-certificate.sha256](release-certificate.sha256).

## Выполнено

- `make check`: 89 Flutter-тестов, анализатор/формат, repo/tool safety guards.
- `make native-test`: 5 Surface + 3 processed-size + 8 native recovery regressions. Back pair даёт ровно один pop; неправильный package, не-APK, старая/та же версия, чужой/пустой сертификат отклоняются; корректный новый кандидат принимается.
- Проверочная release APK успешно собрана. `apksigner` подтвердил тот же сертификат, что у сохранённого 1.7.0. Сверены package/version, min/target SDK, label, ABI и permissions.
- Сохранённый APK в `dist/` не перезаписан. Проверочная сборка находится только в игнорируемом `build/`, не выдается как новый выпуск.

Эти проверки не доказывают runtime всех функций на конкретном Android TV. Проектор/телевизор, аккаунт, Cast и реальные установка/голос не использовались. При будущем выпуске из восстановленных исходников вновь выполнить разрешённую проверку точного APK по [TESTING](TESTING.md). Предыдущие runtime-свидетельства относятся к сохранённому 1.7.0, не автоматически к восстановленной сборке.
