# Текущий статус MJAnime

Срез: **14 ноября 2026**, приложение **1.8.0+17**. Источник версии — `pubspec.yaml`; этот файл — текущая сводка, не журнал всех прошлых утверждений.

## Работает в реализации

- Flutter TV-интерфейс: меню только с иконками; фоновый баннер с затемнением внизу слева; карусели на главной и в истории.
- Поиск с системной Android IME, голосовым вводом, фильтрами и историей запросов.
- Аниме, постоянные номера серий, озвучки, связанные сезоны, информация/кадры/персонажи.
- История по последнему открытию; отдельный прогресс; контекстное удаление долгим OK. Списки и профиль.
- HLS/MP4-плеер, управление пультом, продолжение, опенинги, следующая серия, качество/скорость/масштаб.
- Off / Light / настоящие Anime4K CNN S и M, ограничение Full HD, обработка ошибок и фактический статус режима.
- Существующие вход и адресованный этому клиенту Cast реализованы; live-тесты по умолчанию запрещены.

- Добавлены отдельные GitHub-обновления: суточная автопроверка, ручная проверка, загрузка/отмена, проверка APK и существующий системный установщик.
- Репозиторий оформлен в стиле MJReader; CI и подписанные выпуски по тегу.

## Подтверждено для 1.7.0

- 89 Flutter-тестов, анализатор без замечаний; тёмные/светлые экраны отрисованы с локальными данными.
- Подписанный ARMv7/ARM64 APK установлен в изолированном Android 11/API 30 эмуляторе без сети/звука. Все четыре видеорежима показывают движущееся локальное H.264 720p, CNN S/M подтверждены без скрытого fallback.
- В том же APK проверена настоящая системная IME и подтверждение поиска.
- SHA-256 проверенного APK: `c9f4d4804761fa9219f201d938e7532466a3ed303d82b4497cd74c8502d02527`.

## Не утверждать без отдельной проверки

FPS/совместимость GPU Xiaomi L1 Pro, работу аккаунта и реального сервера в последней сборке, полный паритет оригиналу, live Cast/голос/системное обновление на всех Android TV. Ошибка DNS на эмуляторе с отключённой сетью не свидетельствует о недоступности сервера.

Проектор не трогать. Для дальнейших GPU-проверок использовать только явно разрешённый изолированный эмулятор. Ключ релиза хранится приватно вне Git; его потеря не исправляется новым ключом без потери возможности обновлять установленное приложение.
