# Работа над MJAnime

Как и в [MJReader](https://github.com/MJSasha/mj-reader/blob/main/AGENTS.md), общая точка входа для человека и AI — [AGENTS.md](AGENTS.md). Читать только документы и модули, нужные для текущей задачи.

1. Описать наблюдаемую проблему и ожидаемое поведение. Найти путь по [архитектуре](docs/ARCHITECTURE.md).
2. Сохранить совместимость package/подписи, прогресс, фокус пульта и существующие функции. Не менять framework/зависимости попутно.
3. Добавить одну осмысленную регрессию для изменения поведения. Выполнить `make check` и нужные проверки из [TESTING](docs/TESTING.md).
4. Для UI сравнить реальные рендеры с выбранным дизайном, проверить обе темы, стрелки/Back, длинные подписи, системный ввод и отключённые анимации. Использовать локальные публичные fixtures, не личный аккаунт.
5. Проверить staged diff и `python3 tools/repo_check.py`. Коммитить только относящиеся к задаче исходники. Сообщить реально выполненные проверки и ограничения.

Устройства пользователя не использовать. Подпись не пересоздавать, установленное приложение не удалять ради обновления. Публикация/remote/теги — только по отдельному запросу; [выпуск и восстановление](docs/RELEASING.md).
